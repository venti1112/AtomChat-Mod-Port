# 0.4.0 输入工具与界面完善

> 本文记录初版候选，已被用户拒收，不代表当前验收通过；最新需求和返工状态见 `docs/verification/2026-10-28-ui-corrections.md`。

**目标：** 在既有 Skija 手机／半屏界面内加入聊天搜索、在线玩家入口、确认弹窗、点击水波纹和同风格指令补全，并小幅增强预设配色。

**已确认：** ＋按钮上浮菜单顺序为搜索／玩家／图片。搜索覆盖当前服务器／世界保留的全部本地历史，含公屏／私聊筛选与消息定位。搜索和玩家使用面板内页面，返回保留草稿与滚动位置。确认弹窗用于清空聊天记录、清除壁纸、清理图片缓存，默认取消，Esc／遮罩取消。新增四款明显半透明且模糊的主题，深浅各两款。保留按压／回弹，叠加淡水波纹，跟随全局动画开关。

## 组件族群与职责

| 内容 | 族群／复用点 | 独立职责 |
| --- | --- | --- |
| ＋入口 | chrome 方形动作按钮，UiLayout／UiTokens | 仅打开菜单 |
| 工具菜单 | MenuPopup 固定深色浮层 | 三行按钮的几何、绘制、交互 |
| 搜索／在线玩家 | 面板内列表页，沿用标题栏／返回和卡片排版 | 搜索模型与在线玩家快照分别管理，业务通过窄接口回调 |
| 确认弹窗 | 模态层，UiCards 卡片材质，按钮族 | 焦点、确认／取消、遮罩与输入隔离；删除动作仍由设置业务执行 |
| 指令补全 | MenuPopup 菜单行族 | 原版提供候选与键盘语义，Skija 绘制及坐标适配 |
| 水波纹 | 共享按钮反馈 | 有界动画、圆角裁切，不改命中区域，不扩散到聊天正文 |
| 主题 | ThemeService 颜色与材质快照 | 旧预设小幅增强对比度，新增四个透明预设，不覆盖个人保存预设 |

## 实施顺序

- [x] 1. 对照原有导航、历史存储和点击路由，确定窄接缝；不更换渲染范式，不增加 UI 框架。
- [x] 2. 主题：增强文字／表面对比，新增深浅各两款透明预设；保持预设 ID 和个人预设兼容，更新中英文语言。
- [x] 3. 确认弹窗：独立组件及可测状态，接入三项既有清理动作；确认前不产生删除副作用。
- [x] 4. 工具菜单与页面：搜索模型、结果列表、在线玩家列表分文件；＋替换图片图标，图片仍调用原上传入口。原版玩家名插入光标位置。
- [x] 5. 指令补全：保留服务端／Brigadier 候选和原版补全逻辑，菜单表面与字号、选中态走 AtomChat；覆盖 Tab、方向键、滚轮、鼠标、tooltip 和边界。
- [x] 6. 点击反馈：复用现有按压动画，水波纹按按钮轮廓裁切、资源有界、禁动画清空。
- [x] 7. 集成三端，同步 official／Fabric 等价源码和 seams；独立审查本轮实质改动。
- [x] 8. 定向测试先红后绿，三端完整 test build、孪生／目标矩阵／接缝／日志／裸值与 diff 检查；保存实际离屏图并检查。
- [x] 9. 更新 STATUS 和验证记录，按既有授权构建和部署明确测试实例，备份旧包并核验哈希。游戏内观感、多人和整合包行为留待用户实测，不宣称自动化已覆盖。

## 验证重点

搜索覆盖折叠历史，空查询和中文输入、私聊分流、记录清空与断线使旧结果失效、点击结果确实定位消息；玩家只展示当前连接在线名单。模态阻断底层点击／滚轮／键盘／原版补全，确认只执行一次，关闭或页面切换不保留危险回调。水波纹连点有界、圆角为零和窄布局正确裁切。主题与所有新组件验证手机／半屏、深浅主题、中文／英文、大内容缩放。三端均须验证，不以单端编译推断全部通过。
