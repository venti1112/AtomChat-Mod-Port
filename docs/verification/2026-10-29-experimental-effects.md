# 实验性内容：SkSL 全屏特效

2026-10-29，基于 main@93f58a1 的现有未提交工作继续开发，前序 UI 和图标已获用户验收。本轮未提交、推送或发布

## 用户可见行为

- 聊天设置的高级页，在“趣味特效”下一组新增“实验性内容”，只包含“启用实验性内容”一个开关，旧配置和新配置均默认关闭
- 手动从关切到开，播放一次三秒全屏星云、引力透镜和扩散冲击波；加载已有开启配置、重进界面或从 HUD 编辑器返回不会重播
- 开启后，可见当前聊天的新消息中，“震惊／冲击波／🌊／shocked／shockwave”触发水波，“冷死了／结冰／❄／freezing／frost”触发冰霜，“黑洞／🕳／black hole”触发引力透镜
- 共用原有命令、网址、代码、引用排除逻辑；多个关键词取最早命中，播放中丢弃新触发，不排队
- 此开关独立于旧 Emoji 趣味特效开关，服从全局动画开关；禁用、失去当前会话可见性或退出屏幕后停止，之后不补播
- 仅当前聊天屏幕拥有订阅，不在背景 HUD、历史载入或其他会话上自动触发

## UI 族群与渲染边界

折叠标题、分组卡片和开关均沿用现有 SettingsSectionPage、SettingsItem、ToggleSwitch，间距、hover、回弹、圆角和主题色不另造一套

新标题图标为原子轨道与星芒组合，手写于 SettingsGroupGlyphs 的 20 单位路径，仍由 DrawPrimitives 的统一尺寸、线宽、圆端和边界居中绘制；完整键名登记，不使用关键词猜测图标

全屏演出属于内容装饰层，放在 drawPhone 完成、面板变换恢复后绘制；shader 使用归一化屏幕坐标，独立于 GUI 比例与面板圆角。没有新增弹窗、按钮、输入拦截或设置子页面

画面由当前 Skia Surface 在当前帧采样，图像、子 shader、uniform data、输出 shader 和 Paint 均在当前绘制作用域释放，不跨帧或 context.resetAll 保存 GPU 图像。旧 snapshotWorld 路径保持不变。RuntimeEffect 仅首次有效播放时创建，禁用和无播放时不编译或采样，移除屏幕时释放

## 实施与独立审查

状态、关键词匹配、shader 源和 native 绘制各自独立小类；ChatEffectPresentation 只接现有可见消息订阅和屏幕生命周期，双设置映射及三屏幕适配接线一致

独立强模型初审发现并修正三个 P2：HUD 编辑器返回复用已关闭对象、shader 输出未预乘 alpha、全帧 SRC_OVER 重复合成。现改为重新安装时以当前配置重建会话、先还原直通色再预乘输出、整帧显式 SRC。修复均有旧实现失败日志；限定复查通过，另独立原生像素探查 120 组通过，不扩大为此前全部 0.4.0 独立审查

首次原生出图还发现负数底数 pow 导致饱和填充，已将两处平方改为显式乘法，并用黑洞中心和水波内部实际像素回归约束

### 帧成本范围

GPU 为本机 NVIDIA GeForce RTX 5060 Laptop，非 Minecraft 场景。计时包含当前效果的采样、绘制、提交与等待完成，不含前置场景绘制和截图读回，不代表游戏整帧
